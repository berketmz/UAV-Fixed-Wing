# Fixed-Wing UAV SolidWorks Design

This project is a personal design study of a fixed-wing Unmanned Aerial Vehicle (UAV), created in SolidWorks. The primary objective of this project was to practice CAD modeling, refine mechanical design skills, and apply aerospace design principles in a practical environment.

## 📝 Project Overview
This is a self-initiated hobby project focused on professional development. My main goal was to improve my proficiency in fuselage design, wing aerodynamics, assembly logic, and mechanical detailing within the SolidWorks ecosystem.

## 🛠️ Technical Details
The design process emphasizes precision and structural integrity. Key areas of focus include:
* **CAD Software:** SolidWorks
* **Design Pillars:**
    * Fuselage geometry and internal structuring
    * Aerodynamic wing surface modeling
    * Complex assembly and component integration
    * Design for Manufacturing (DFM) principles
